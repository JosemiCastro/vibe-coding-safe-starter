# Checklist: landing o web corporativa

## Antes de publicar
- [ ] build correcta
- [ ] dominio y SSL correctos
- [ ] enlaces y CTAs revisados
- [ ] variables públicas revisadas
- [ ] analytics o píxeles comprobados si aplican

## Conversión
- [ ] formulario envía
- [ ] mensaje de éxito y error funcionan
- [ ] lead llega al destino correcto
- [ ] email o teléfono visibles son correctos
- [ ] versión móvil revisada

## Privacidad y seguridad
- [ ] no hay claves secretas en frontend
- [ ] no se recogen datos innecesarios
- [ ] enlaces legales funcionan si aplican
- [ ] logs no muestran datos sensibles

## Rollback
- [ ] build anterior disponible
- [ ] sé limpiar caché si aplica
- [ ] sé comprobar home, CTA y formulario tras revertir
