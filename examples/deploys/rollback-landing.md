# Ejemplo de despliegue: landing o web sin datos críticos

## Escenario
Cambias contenido, estilos o secciones públicas.

## Antes del deploy
- build correcta
- formularios y enlaces revisados
- dominio y SSL correctos

## Deploy
1. sube nueva versión
2. revisa home y páginas clave
3. prueba formularios o CTAs

## Rollback
Si falla:
1. vuelve al build anterior
2. limpia caché si aplica
3. vuelve a probar la home y formularios
