# Contributing

Si quieres mejorar este repo:

1. prioriza claridad sobre complejidad
2. añade ejemplos reales antes que teoría genérica
3. no metas consejos inseguros por acelerar
4. cualquier recomendación de deploy o seguridad debe ser verificable
5. si propones scripts, deben venir explicados y marcados como plantilla si no son listos para producción
